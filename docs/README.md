# Docs

- `foundation.md` — the current cheat-sheet: every token utility, CSS variable and `src/lib/m3` export, with usage. Read this first when writing UI here or borrowing from this repo.
- `research/` — the Material 3 Expressive spec values (sizes, colors per state, type, shapes, springs) collected from Google's published docs and source, each with its sources. Where sources disagree, the files say so.
- `plan.md` — the original architecture plan the build agents followed. Historical; the code and `foundation.md` win where they differ.
